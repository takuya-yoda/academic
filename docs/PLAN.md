# Academic ウェブサイト 構築プラン

## 目的
- プロフィール情報の整備
    - 閲覧者が所有者の経歴を把握するため
    - 所有者自身が書類作成などの際に参照するため
- 便利情報の共有
    - 講義資料，開発コード，推奨される書籍情報など
- 自身の研究内容の紹介（将来実装）

## 方針
- 単純な最小構成
    - 管理コストを小さく抑える
    - セキュリティ対策，外部ツールからの影響から隔離
- 言語は英語で統一
    - 管理コストを小さく抑える
    - 今後国内向けに，日本語のページを追加する可能性あり
- データベースを分離
    - 自動的な取得，解析，整理に備える

## 掲載内容

### 構成
- トップ
    - 氏名・顔写真
    - 所属
    - 研究内容・キーワード
    - 連絡先
    - サイトマップ・更新履歴

- 研究業績
    - 出版物
    - 学会・研究会発表
    - セミナー発表

- 有益情報
    - 講義資料(PDF, GitHubリンクなど)
    - 開発コード(GitHubリンクなど)
    - 関連組織へのリンク

- 履歴情報
    - 雇用履歴
    - 学歴
    - 獲得資金
    - 受賞歴
    - 教育経験


### フィルタ
一部項目にはフィルタを設置し，注目したい情報のみが表示されるようにする

- 出版物
    - 論文/その他

- 学会・研究会発表
    - 国内/国際
    - 口頭発表/ポスター発表
    - 招待

- セミナー発表
    - 国内/国際
    - 招待
